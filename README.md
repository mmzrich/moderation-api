# Сервис модерации объявлений

Учебный HTTP API на Python и FastAPI. `POST /predict` возвращает одно JSON-значение
`true` или `false`: **`true` означает, что в объявлении есть нарушение**.

Правило модерации:

| Продавец подтверждён | Изображения | Есть нарушение |
| --- | --- | --- |
| Да | Любое допустимое количество | `false` |
| Нет | Одно или больше | `false` |
| Нет | Нет | `true` |

## Установка и запуск

Нужен Python 3.11 или новее. Проект проверен на Python 3.13.
Все команды выполняются из папки проекта.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
fastapi dev
```

API доступен по адресу <http://127.0.0.1:8000>, интерактивная документация —
<http://127.0.0.1:8000/docs>. `fastapi dev` автоматически находит `app` в `main.py`.
Пакет `fastapi[standard]` включает CLI и сервер для этой команды.

## Запрос

Все семь полей обязательны. Тело запроса — JSON-объект.

| Поле | Тип | Валидация |
| --- | --- | --- |
| `seller_id` | `int` | Больше нуля |
| `is_verified_seller` | `bool` | JSON `true` или `false` |
| `item_id` | `int` | Больше нуля |
| `name` | `str` | Непустая строка после удаления пробелов по краям |
| `description` | `str` | Непустая строка после удаления пробелов по краям |
| `category` | `int` | Больше нуля |
| `images_qty` | `int` | Ноль или больше |

Типы проверяются строго: `"1"`, `1.0` и `true` не принимаются вместо целого числа,
а `0`, `1` и `"false"` — вместо булева значения. `null` и дополнительные поля
запрещены. Положительные идентификаторы и непустые строки — принятые в проекте
ограничения, уточняющие условие задания.

```sh
curl -X POST http://127.0.0.1:8000/predict \
  -H 'Content-Type: application/json' \
  -d '{"seller_id":1,"is_verified_seller":false,"item_id":10,"name":"Велосипед","description":"Городской велосипед","category":2,"images_qty":0}'
```

Ответ с кодом `200`:

```json
true
```

При `is_verified_seller: true` или `images_qty: 1` ответ будет `false`.

## Статусы и ошибки

- `200` — успешный прогноз, тело ответа содержит только JSON boolean.
- `400` — отсутствуют обязательные поля, неверны типы или значения, повреждён JSON.
  Тело содержит `detail`: список ошибок с полями `loc`, `msg` и `type`.
- `500` — неожиданная ошибка сервиса или репозитория. Ответ:
  `{"detail":"Internal server error"}`. Подробности ошибки записываются в журнал
  сервера.

FastAPI по умолчанию использует `422` для ошибок валидации. В этом проекте
обработчик `RequestValidationError` заменяет его на требуемый `400`;
OpenAPI-схема отражает этот контракт.

`GET /` возвращает `{"message":"Hello World"}`, как в стартовом примере задания.
Неиспользуемый импорт `routers.users` из примера заменён подключением роутера
предсказаний.

## Архитектура

```text
main.py                      приложение и обработчики ошибок
routers/predict.py           HTTP-обработчик и внедрение зависимости сервиса
schemas/prediction.py        модели входных данных и ошибок
services/moderation.py       бизнес-правило и сохранение результата
repositories/predictions.py  интерфейс хранилища и реализация в памяти
tests/                      тесты API, сервиса и репозитория
```

Сервис получает репозиторий через конструктор. Репозиторий сохраняет последний
результат для каждого `item_id` и не содержит бизнес-правил. Для задания отдельная
БД не нужна: данные хранятся в памяти процесса и теряются после перезапуска;
при нескольких процессах у каждого своё хранилище. HTTP-метода чтения истории нет.

## Тесты

```sh
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Параметризованные тесты проверяют комбинации статуса продавца и числа фотографий,
обязательные поля, строгие типы, допустимые границы и повреждённые тела запросов.
Отдельно проверяются бизнес-логика, сохранение и обновление результата,
изолированность репозиториев, ошибки бизнес-логики и хранилища.
